h3. redmine_expert_checklists 0.2.0 — 2026-11-09

h4. Added

* Switch from RedmineUP Checklists project by project: the import page (and the rake task with @PROJECTS=@) switches chosen projects while RedmineUP stays installed for the others. Their checklists are copied again, their saved queries converted, *expert Checklists* switched on and RedmineUP's module off, in one transaction. RedmineUP's permissions have to be in a project module of their own for this; the README lists the changes.
* RedmineUP's history entries are shown in switched projects, and copying an issue from a project still on RedmineUP takes RedmineUP's items.

h4. Changed

* While RedmineUP is installed, the checklists step copies issues of projects without our module again (and drops copies whose RedmineUP checklist has since been emptied) instead of skipping issues copied earlier.
* The project module step also switches RedmineUP's own module off where it has one and always copies the checklists first. Next to an installed RedmineUP it is no longer preselected.
* Import steps always run in their fixed order.
* Tested on MySQL 8.4 and PostgreSQL 17 as well.

h4. Upgrade notes

No migrations. Replace the plugin directory and restart.
