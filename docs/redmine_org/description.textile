Checklists on Redmine issues. Tick items right on the issue page, edit the list in the issue form, and find every change in the issue history. Quick ticks by one person are bundled into *one history entry and one mail*, sent in the background, so a click answers at once instead of waiting for a mail per watcher.

h3. Features

* *Issue page:* checklist block under the description with sections, progress and "Hide done". Ticking saves without a page reload; the edit form on the same page stays in step.
* *Issue form:* add, rename, tick, delete and reorder items (drag or Alt+Up/Down). Paste several lines to add one item per line; @--@ starts a section, @[x]@ marks an item done.
* *History:* one line per changed item ("Checklist item _Buy milk_ done"), also in notification mails and the PDF export. Users without the view permission see neither the lines nor the mails.
* *Bundled mails:* ticks by the same user within 60 seconds share one history entry and one notification, sent once the user stops. Pending mails are stored, so a restart does not lose them. Setting: like issue updates, always or never.
* *% Done from the checklist* and *block closing while items are open* (both optional).
* *Copying* an issue copies its checklist, including bulk copy, project copy and subtasks.
* *Issue list:* "Checklist" column (also CSV and PDF) and filters by item state and item text.
* *REST API* (JSON and XML) for items, plus nested items on the issue API. Paths and field names of RedmineUP Checklists keep working once that plugin is removed.
* *Import from RedmineUP Checklists:* items with their ids, permissions, settings, saved queries and the project module, with a dry run first. RedmineUP's history entries stay readable.
* Project module *Checklists* with the permissions view, tick and edit.

h3. Languages

User interface in English, German, Spanish, French, Italian and Portuguese (Portugal and Brazil); other languages fall back to English. Documentation in English and German.

h3. Requirements

Redmine 5.1, 6.0, 6.1 or 7.0. No extra gems.
